# Party video: Saturday recording checklist
*Goal: one ~60-second edited video of the 5 beats (also the Devpost video). It only has to work once.*

## ⏰ Hard deadline
- [ ] Bakery closing time: **____**. Start recording no later than **closing − 90 min**: ____
- [ ] Bakery visited + agreed (see BAKERY_CALL.md); expected call time: ____

## Before recording (T−60 min)
- [ ] Photon: iMessage line live, SMS number + Voice profile → ElevenLabs/Retell working (one test call to a teammate)
- [ ] Guests: 4 friend phones (teammates + optional judge) unlocked, volume up, Do Not Disturb off, within Photon seat cap
- [ ] Chrome: DoorDash logged in (persistent profile), saved payment method or capped virtual card, delivery address = JWAC
- [ ] Virtual card limit set (≤ $100 real spend)
- [ ] Hive engine + Mac app running; notch shows budget bar; Call window ready
- [ ] (Optional) iPad + Procreate invite sketch, only if it passed rehearsal
- [ ] Engine "party" scenario rehearsed once end to end **without** placing the real order or calling the bakery

## Camera setup
- [ ] **Screen recording** of the Mac (QuickTime → New Screen Recording, with the internal + call audio)
- [ ] **Camera** (phone on a tripod) framing the laptop edge + the friends' phones + your phone, so phones buzzing are visible
- [ ] **Clock visible** in both: the menu-bar clock + a phone showing the time in frame
- [ ] Mic: call audio audible (Mac speakers near the camera mic, or capture directly)
- [ ] Final video = **split-screen** (screen left, camera right) so key moments have no cuts

## The take (single continuous run)
1. Text Hive the request
2. Invites go out → phones buzz → "I'm vegan" reply → vegan item added
3. Bakery call (disclosure → order → read-back)
4. Over-budget question → "swap"
5. Cake text summary → "add 🎉?" → callback
6. Real DoorDash order → tracking page
7. Split → requests sent

**If something breaks mid-take:** keep recording, fix it, continue. Edit later and say so on screen ("⏩ 2 min skipped").

## After recording
- [ ] Screenshot the **DoorDash receipt** + tracking, and the **bakery confirmation** (text/receipt)
- [ ] End card of the video: receipts + "Recorded Sat Oct 17, [time], one take"
- [ ] Pick up the cake 🎂 (bring it to judging as a prop!)
- [ ] Food arrives at JWAC: take a photo for the video's last frame
- [ ] Export: 1080p, ≤ 90s, captions on (judging rooms are loud)
- [ ] Upload as the Devpost video
